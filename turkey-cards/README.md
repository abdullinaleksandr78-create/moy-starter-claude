# Карточки постов «Пространство Аланья»

Единый стиль: тёмно-синий + золото, логотип «РСП» в золоте, иллюстрация по теме поста.
Из одного описания рисуются две картинки:

- `<имя>-tall.png`, 1080×1350 (4:5): Instagram, Threads;
- `<имя>-wide.png`, 1280×720 (16:9): Telegram.

## Запуск

```bash
python3 render.py card.json out/ --name 2026-09-26-rayony
```

Код выхода 2 означает, что заголовок не влез: сократите его и запустите снова.

## Поля card.json

| Поле | Что это |
|---|---|
| `topic` | иллюстрация, см. ниже |
| `kicker` | рубрика над заголовком: «Гражданство», «Сезон и быт», «Обзор объекта · Махмутлар» |
| `date` | ДД.ММ.ГГГГ |
| `title` | заголовок, до ~40 знаков, выводится капсом |
| `subtitle` | 0–3 коротких строки (строка или список) |
| `takeaway` | «Что это меняет» — одна фраза для клиента |
| `footnote` | источник и дата проверки |
| `items` | необязательно: числа для графиков (`rate`, `stats`) или 6 подписей месяцев (`calendar`) |
| `photo` | только для `property`: путь или URL фото, будет вписано в арку |

## Темы (`topic`)

| topic | Когда | Рисунок |
|---|---|---|
| `districts` | районы, кварталы открыты/закрыты | сетка кварталов, открытые — золотом |
| `rate` | курс лиры, ЦБ, пороги 200/400 тыс. $ | график с линией порога |
| `law` | законы, правила ВНЖ/гражданства, проверки, аннулирования | документ с печатью |
| `calendar` | 90/180, зимовка, сроки, афиша, каникулы | календарь 180 дней, 90 — золотом |
| `stats` | статистика продаж, цены, число ВНЖ, турпоток | столбцы, последний — золотом |
| `payments` | переводы, карты, банки | две карты и перевод RUB→TRY |
| `tariffs` | тарифы, коммуналка, стоимость жизни | ступени тарифа и лампа |
| `property` | обзор/показ квартиры | арка (с фото, если есть) |

Примеры — в `examples/`.

## Макеты по рубрикам (с 14.10.2026)

Чтобы лента не сливалась, у каждой рубрики свой макет. Поле `layout` в card.json:

| layout | Рубрика | Что на картинке | Поля |
|---|---|---|---|
| `cities` | «Три города» | три арки с фото Стамбула, Антальи, Алании и цифра под каждой | `cities`: список `{key, name, value, note}`, `key` — `istanbul`/`antalya`/`alanya` |
| `steps` | «Как это устроено» | шаги 01–05 с золотой линией | `steps`: список `{t, d}` |
| `qa` | «Вопрос — ответ» | крупный вопрос, короткий ответ, большой «?» | `question`, `answer`, по желанию `portrait` (фото Лилии) |
| `checklist` | «Чек-лист» | пункты с золотыми галочками | `checklist`: список строк |
| `photo` | новости | фото города на весь фон, заголовок поверх | `photo`: `alanya`/`antalya`/`istanbul`/`any`, `subtitle` |
| `classic` или пусто | новости | иллюстрация по `topic` (как раньше) | `topic`, `items` |

- `theme`: `dark` (тёмно-синий) или `light` (молочный). Макет `photo` всегда тёмный.
- `slides` (по желанию): список `{t, d, photo}` — внутренние слайды карусели Instagram. Рисуются как `<имя>-s2.png`, `-s3.png`…; первый слайд — это `-tall.png`.
- Фото городов лежат в `photos/` (Unsplash, см. `photos/README.md`); снимок выбирается по дате и заголовку, чтобы не повторяться день в день.
- Портреты — в `portraits/`.

Примеры всех макетов — в `examples/`.

### Как чередовать (правило для ежедневной задачи)

1. Макет — по рубрике поста (таблица выше). Новостной пост — `photo` с городом новости (если новость общая — `any`); если три новостных поста подряд вышли на `photo`, следующий — `classic`.
2. Тема — по очереди: если вчерашний пост был `dark`, сегодня `light` (кроме `photo`). Смотреть по последней строке раздела 1 накопителя или по последней карточке в `posts/`.
3. Карусель — для «Чек-листа» и «Как это устроено», 3–5 слайдов: в Instagram уходят `-tall.png` и все `-sN.png` по порядку; в Threads и Telegram — только обложка.
4. «Вопрос — ответ» с портретом Лилии — не чаще раза в неделю, если в `portraits/` есть фото.

## Публикация

Готовые PNG коммитятся в ветку `cards`, папку `turkey-cards/posts/`, и открываются по публичной ссылке:
`https://raw.githubusercontent.com/abdullinaleksandr78-create/moy-starter-claude/cards/turkey-cards/posts/<файл>.png`.
Metricool принимает эту ссылку как медиа поста.
