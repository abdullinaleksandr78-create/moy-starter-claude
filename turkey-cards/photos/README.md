# Фото для карточек

Снимки Алании, Антальи и Стамбула для фона и арок на карточках (`layouts.py`).
В `card.json` укажите `"photo": "alanya"` (или `antalya`, `istanbul`, `any`), и снимок подберётся из папки сам, по очереди.

- Источник — Unsplash, [лицензия Unsplash](https://unsplash.com/license): бесплатно, можно в рекламе, подпись автора не обязательна.
  Нельзя продавать сами фото как есть и выдавать их за собственные снимки объектов.
- Имя файла — ID фото на Unsplash: страница снимка — `https://unsplash.com/photos/<ID>`.
- Отобраны вручную, на всех — узнаваемые места своего города (Алания: крепость, Кызыл Куле, Клеопатра, маяк; Анталья: Калеичи, Конъяалты, Хыдырлык; Стамбул: Босфор, Галата, Девичья башня, Айя-София).

## Как добавить фото

1. Найти снимок на Unsplash (только бесплатный, не Unsplash+), взять прямую ссылку `https://images.unsplash.com/photo-…`.
2. Дописать строку в `wanted.txt`: `<город>/<ID> <ссылка>` и закоммитить в ветку `cards`.
3. GitHub Actions (`.github/workflows/fetch-photos.yml`) скачает фото, ужмёт до 1800 px и закоммитит сюда.

Свои фото (например, Лилии) кладутся вручную в `portraits/` — см. README карточек.
