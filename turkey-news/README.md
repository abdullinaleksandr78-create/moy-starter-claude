# Новости Турции — рабочие файлы задачи «Турция: утренний разбор новостей»

Эта папка — память ежедневного разбора. Задача запускается в облаке и не видит ни ваш компьютер,
ни документы проектов claude.ai, поэтому всё, что должно переживать запуск, лежит здесь,
в ветке `cards` — той же, куда уходят картинки постов (`turkey-cards/`).

| Файл | Что в нём | Кто пишет |
|---|---|---|
| `nakopitel.md` | Накопитель: что уже разобрано и по чему был пост, что ждёт развития, темы для Дзена | задача — каждый день; вы — когда хотите |

## Как читать и править

- Смотреть: GitHub → репозиторий `moy-starter-claude` → переключатель веток → `cards` → папка `turkey-news`.
- Править можно прямо на GitHub (карандаш «Edit»), задача подхватит изменения на следующий день.
- Репозиторий публичный: сюда пишем только то, что и так публично (новости, ссылки, темы).
  Никаких данных клиентов, цен сделок, контактов.

## Правила ведения накопителя

1. Новые записи — **сверху** своего раздела, дата в формате ДД.ММ.ГГГГ.
2. Одна новость = одна строка: суть · первоисточник (ссылка) · дата проверки · был ли пост.
3. Если по новости появилось развитие — не создавать новую строку, а дописать в старую `→ ДД.ММ: что изменилось`.
4. «Ждём развития» — то, что пока слух или без официального решения. Когда решение вышло — переносим в «Разобрано».
5. «Темы для Дзена» — не новости, а вопросы «как это устроено», на которые накопились факты.
